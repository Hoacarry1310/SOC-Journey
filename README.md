# 🛡️ SOC Analyst & Blue Team Learning Journey

Kho lưu trữ quá trình tự học, thực hành Home Lab và các báo cáo điều tra sự cố (Incident Investigation Reports) theo lộ trình 12 tuần hướng tới vị trí **SOC Analyst Intern / Junior**.

## 📂 Cấu trúc thư mục
- 📁 **`study-notes/`**: Ghi chú kiến thức nền tảng (Networking, Linux, Windows Event Logs, SIEM).
- 📁 **`investigation-reports/`**: Báo cáo phân tích cảnh báo và Write-up thực hành từ TryHackMe, LetsDefend, CyberDefenders và Home Lab.

## 🛠️ Công cụ & Môi trường thực hành
- **Hệ điều hành & Ảo hóa:** Windows, Ubuntu Linux (VirtualBox)
- **Phân tích mạng:** Wireshark, Nmap, tcpdump
- **Giám sát & Điều tra:** Sysinternals Suite, Wazuh SIEM *(đang triển khai)*
- **Nền tảng thực hành:** TryHackMe, LetsDefend, OverTheWire (Bandit)

## 📈 Tiến độ Lộ trình (12 Tuần)
- [x] **Tuần 0:** Dựng môi trường Lab (VirtualBox, Ubuntu, Snapshot) & tạo Portfolio GitHub
- [ ] **Tuần 1–3:** Nền tảng Mạng (OSI, TCP/IP, Wireshark) & Linux cơ bản
- [ ] **Tuần 4–6:** Windows Internals, Event Logs & Phân tích cảnh báo cơ bản
- [ ] **Tuần 7–9:** Dựng SIEM Lab (Wazuh) & Viết Investigation Reports
- [ ] **Tuần 10–12:** Hoàn thiện CV, Portfolio & Ứng tuyển thực tập
